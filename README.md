# Mimamori 見守り — page et téléchargements

Vos caméras Xiaomi C200 sur le Meta Portal, en local : **https://cyprienbrisset.github.io/mimamori-public/**

Ce dépôt contient seulement la page de présentation, les versions publiées (APK joint à chaque [release](https://github.com/cyprienbrisset/mimamori-public/releases)) et `version.json`, lu par FukkaStore dans [Fukkatsu](https://github.com/cyprienbrisset/fukkatsu-nop) pour installer et mettre à jour Mimamori.

Composants tiers inclus dans l'APK : [go2rtc](https://github.com/AlexxIT/go2rtc) (MIT), police Zen Maru Gothic (SIL OFL 1.1, voir `FONT-LICENSE-OFL.txt`), AndroidX Media3 (Apache 2.0). Mimamori n'est affilié ni à Xiaomi, ni à Meta.
